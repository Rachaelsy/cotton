# 喀什优棉公共服务平台小程序

首页“今日待办”按本地日期读取公共服务后台当天已发布内容。管理员可以维护建议时间、标题、补充说明、语音播报文案、优先级、排序和发布状态；播报文案同时直接显示在首页。待办较少时卡片按实际内容自动收缩，达到最大高度后才固定尺寸并在卡片内部上下滑动，“上下滑动查看更多”也仅在溢出时出现；页面不设置个人完成标记。语音播报复用 `app.json` 已配置的 WechatSI 插件，通过底部导航上方的右下角双层正圆麦克风入口连续读取当天事项；入口使用等宽等高的非原生按钮容器，避免真机被默认样式拉成椭圆，再次点击可以停止。语音入口始终显示，当天暂无待办或接口加载失败时会给出对应提示，不再直接消失。

政策资讯的后台编辑表单包含独立的“原文发布时间”。该时间与平台实际发布/更新时间分开保存，文章列表及详情页优先显示原文时间，并统一输出为 `YYYY-MM-DD HH:mm:ss`。Markdown 正文的普通段落采用两个汉字宽度的首行缩进，标题、列表和引用保持原有层级，不额外缩进。

政策文章评论使用固定底部单行输入栏，发送按钮位于输入框内部；键盘弹起时输入栏随页面调整到键盘上方，不再打开独立的大文本编辑面板。登录农户可以回复任意评论，并对主评论或回复点赞、取消点赞；回复按原评论归组，点赞状态按登录账号隔离。

## “我的”个人中心

“我的”页统一提供实名认证、我的地块、我的学习、收藏与评价、设置与帮助、关于我们六项个人服务。地块与认证读取当前登录账号的后端数据；课程完成状态和政策收藏目前保存在当前设备；意见评价登录后提交至共享后端，并可查看管理员回复。

实名认证属于可选服务，证件资料仅用于身份核验。金融内容只提供公益科普与官方入口指引，平台不办理贷款、投保、开户或交易业务。

项目每日工作进展统一记录在 [`DAILY_PROGRESS.md`](./DAILY_PROGRESS.md)，面向负责人汇报完成事项、验证结果、风险和下一步计划。

`cotton-public` 是面向棉农的“喀什优棉公共服务平台”小程序，提供农技学习、政策资讯和生产服务。项目以 `demo/index.html` 为产品和视觉参考，复用 `cotton-app` 已验证的农业生产功能，并通过同一套 Node.js + Express + MySQL 后端读取用户、地块、气象、农事记录、专家内容和 AI 数据。

政策资讯、专家讲堂、优棉金融、农机服务、农资服务、加工服务和品种优选已同时接入公共服务网站。管理员在 `/knowledge/policy-admin.html` 维护一次内容，选择发布后，小程序与 `/public/` 网页端从同一数据库读取；无需复制文章或重复录入。网页入口如下：

| 模块 | 公共服务网页入口 | 共享公开接口 |
|---|---|---|
| 政策资讯 | `/public/policies` | `/api/policies` |
| 专家讲堂 | `/public/experts` | `/api/expert-studio/public` |
| 优棉金融 | `/public/finance` | `/api/policies?type=finance` |
| 农机服务 | `/public/machinery` | `/api/service-products?type=machinery` |
| 农资服务 | `/public/supplies` | `/api/service-products?type=supplies` |
| 加工服务 | `/public/processing` | `/api/processing-factories` |
| 品种优选 | `/public/varieties` | `/api/cotton-varieties` |

只有已发布/已上架记录会在两个公开终端显示。管理员保存草稿、下架产品、下线加工厂或停用专家后，公开网页和小程序会遵循相同状态规则。

首页“首页推送”统一展示后台精选的政策、行业、金融和公共服务内容，最多同时展示 5 篇。小程序正文使用 `24rpx` 的全局基础字号和 `1.5` 行高，各页面辅助文字在不改变标题层级与布局的前提下适当放大，便于真机连续阅读。

小程序导航入口使用“图标＋功能名称”的简洁结构，不在入口标题下重复罗列功能关键词；文章来源、时间、产品型号、状态和风险提示等业务信息仍正常展示。政策与金融文章的评论、收藏、转发使用固定宽度的底部右侧操作组，并覆盖微信原生分享按钮的默认间距；评论输入框在左侧自适应。

首页常用工具和生产服务共使用 12 枚统一的农业线性图标，分别表达地块、识别、天气、政策、专家、记录、学习、金融、农机、农资、加工和品种优选。图标保存在 `images/home-icons/`，使用小尺寸本地透明 PNG，不依赖网络图片，也不再使用单个汉字或长 SVG 数据地址作为图标。

普通内容页面默认使用 WebView 的页面自然滚动；地块、病虫害、气象、专家等复杂页面可单独使用 Skyline，但必须包含明确高度的纵向 `scroll-view`。不要在 `app.json` 全局强制 Skyline，否则首页、资讯和详情等自然文档流页面在真机上会无法上下滑动。

公共服务管理员统一从 `/admin/login.html?role=admin` 登录。后台左侧包含“政策资讯”“优棉金融”“首页推送”“今日待办”“专家讲堂”“农机服务”“农资服务”“加工服务”“品种优选”“农户管理”“地块管理”和“账号安全”；退出后返回统一登录页，旧的独立运营登录页已删除。
账号安全的密码修改复用政策后台 API 通道，可避免服务器代理配置不同步造成的网络连接失败。

本地网页与共享后端开发使用仓库根目录的 `scripts/dev-local.ps1`，统一访问
`http://127.0.0.1/`。本地配置保存在不会提交 Git 的 `.env.development`，不会改动云服务器环境。
本地开发覆盖配置默认使用 Docker Hub 官方 Node、MySQL 和 Nginx 镜像，生产 Compose 仍保留服务器原有镜像地址。若当前网络无法拉取镜像但本机已有可用缓存，启动脚本会自动回退为 `--no-build`；也可显式运行 `scripts/dev-local.ps1 -NoBuild`。修改 `package.json` 或基础镜像后必须恢复联网并重新构建，不能长期依赖旧缓存。
本地公共服务管理员可通过 `COMMUNITY_ADMIN_PASSWORD` 临时环境变量配合 `db/create_community_admin.js` 创建，密码不会写入项目配置。
公共服务管理员后台将共享数据拆分为“农户管理”和“地块管理”。农户页处理脱敏基本信息、认证、账号状态及新增编辑；地块页专门展示地图、种植生产、风险提醒和区域统计。两页共用智能体后端数据，但该账号不继承商户、订单等其他核心管理权限。

## 当前迁移范围

- 公共服务平台新首页：顶部当前位置天气与农事提示；常用工具集中展示地块管理、病虫害识别、地块气象、政策资讯、专家讲堂、农事记录、优棉学堂和棉花金融；同级生产服务模块提供农机、农资、加工和品种优选四个服务入口。
- 生产服务：首页提供农机、农资、加工和品种优选四个独立模块。农机服务和农资服务不是知识科普页，而是由公共服务管理员运营的具体产品目录：后台录入名称、机型/品种、品牌、厂家、图片、简介、产品特点、适用条件和地区，只有“已上架”产品会进入小程序。加工服务介绍轧花、检测、仓储三个环节，并通过 `/api/processing-factories` 从数据库读取加工厂列表、县域筛选、地图点位和独立详情；后台可维护名称、经纬度、地址、年加工产能、负责人、联系电话、简介、图片 URL、服务范围和公开核验信息，只有“已发布”记录会进入小程序。首批数据来自自治区公示名单与公开地图 POI 交叉核验；未公开字段不作推测。平台展示公开服务资料，不直接交易、收款或提供推荐、认证与履约担保。
- 品种优选：首批录入《2025年喀什地区棉花品种对比试验各项指标统计表》中的 22 个品种，完整展示衣分、上半部平均纤维长度、断裂比强度、马克隆值、整齐度、籽棉产量及各单项名次。综合值沿用原表权重：衣分 15%、纤维长度 20%、强度 20%、马克隆值 10%、整齐度 20%、产量 15%，数值越低代表综合名次越靠前。列表支持综合、产量、纤维品质和衣分排序：只有综合优选显示综合名次；其他栏目分别突出产量名次、纤维品质专项名次和衣分名次，并同步显示对应单项数值。详情页说明试验边界，并为后续县域主推品种、适宜条件和棉田匹配分析预留结构。公共服务管理员可在后台新增、编辑、发布、下线和删除历年试验资料。
- 棉花资讯：推荐、政策、农技、市场、气象分类列表。
- 政策资讯：首页常用工具入口，下设“政策中心”和“行业资讯”。政策中心按国家、自治区、地区、县级分层；行业资讯按产业、农机、农资、市场、气象分类。列表采用简洁资讯流，详情页使用深绿主题文章头，并按“栏目、标题、来源与时间、Markdown 正文、评论”的顺序阅读，支持登录评论、本机收藏和微信转发。
- 首页内容板块正式命名为“首页推送”，由同名后台统一运营，不再使用小程序内置静态文章。政策、行业和金融文章均可推送，也可新增不出现在任何栏目里的首页专稿；全平台最多同时推送 5 篇，首页点击会按类型进入正确详情页。
- 优棉金融：首页顶部展示棉花主力连续行情，包含合约、最新价、涨跌、更新时间、数据来源和延迟状态；行情由 `cotton-community` 服务端适配层获取，默认使用公开行情并支持通过环境变量切换正式授权数据源，取数失败时不显示估算或虚构价格。种植贷、棉花保险、期货基础和金融政策解读分别对应数据库中的一篇 Markdown 文章，管理员可编辑、发布和推送首页；文章页支持评论、收藏和转发。不提供贷款申请、保险销售、期货开户、交易撮合、荐单或收益承诺。
- 优棉学堂：初级、中级、高级阶梯课程，支持图文课、视频课、课程积分和阶段考试。
- 地块管理：列表、地图绘制、新增地块、地块详情。基础信息与后台共享名称、面积、边界、品种、播种日期、灌溉、土壤、种植状态、生育期和备注；生育期按播种出苗期、苗期、蕾期、花铃期、吐絮收获期五类管理，可人工校正，未校正时按播期自动推算。地块地区和乡镇目前继承农户账号档案，不是每块地的独立编辑字段。
- 病虫害识别：拍照/相册识别、识别结果和病虫害详情；识别历史与总次数由后端按登录账号隔离，多账号不会共用记录。
- 地块气象：左上角下拉选择当前位置或本人地块，并按所选位置重新获取气象；展示未来 24 小时、未来 7 天趋势、降水/风力/高温风险、灾害预警和农事建议。无地块时仍可查看区域预报，定位不可用时降级为喀什参考预报。
  下拉面板使用页面根层固定浮层，兼容 Skyline 真机点击区域；地块选项不会被顶部容器边界或背景遮罩拦截。
- 专家讲堂：小程序顶部使用“精选问答 / 在线专家 / 精选视频”三栏导航。公共服务管理员可在后台新增和编辑专家资料、问答和视频，上传专家头像、视频封面及视频文件，设置分类、讲解专家、排序、精选和发布状态；只有已发布内容与启用专家会公开展示，同时保留农户在线提问和本人回复记录。
  精选问答是棉花生产常见问题库，不属于课程：列表展示问题和简短答案，详情按“问 / 答”结构展示完整解答；后台字段对应“问题、答案摘要、完整答案”，小程序和网页端同步呈现。首批内置 14 条常见问题，覆盖播种、出苗、苗期、水肥、花铃期、棉蚜、红蜘蛛、棉铃虫、黄萎病、气象灾害、脱叶和机采。内容只作为调查和管理思路，具体农药、调节剂、水肥量及作业参数仍以登记标签、属地技术方案和现场判断为准。初始化使用一次性批次标记，管理员后续编辑或删除不会被容器重启覆盖。
- 农事记录：记录列表、增删改和独立农事日历。
- AI 农技问答、手机号登录及微信一键登录基础页面。

底部导航为“首页 / AI助手 / 我的”。优棉学堂不占用底部导航，继续从首页常用工具进入。首页天气使用定位接口读取真实数据，并根据真机状态栏与微信胶囊动态预留顶部安全区；地点、温度区间、风力和农事建议支持多行完整显示。用户拒绝定位或网络不可用时只展示降级提示。

公共服务平台拥有独立、可扩展的管理后台。管理员从统一入口 `/admin/login.html?role=admin` 登录：进入“政策资讯”可使用 Markdown 发布文章；进入“优棉金融”可维护四个金融专题；进入“首页推送”可管理全平台首页推荐并新增首页专稿；进入“今日待办”可按日期维护首页任务和语音文案；进入“专家讲堂”可运营精选问答、在线专家和精选视频；进入“农机服务”或“农资服务”可新增、编辑、上架、下架和删除具体产品；进入“加工服务”可维护加工厂资料、地图坐标和发布状态。专家运营管理接口为 `/api/expert-studio/admin/*`，小程序通过 `/api/expert`、网页端通过 `/api/expert-studio/public` 读取相同表；媒体保存在公共服务持久化上传目录。草稿、下架内容及停用专家不会在小程序或网页端公开展示。创建账号和部署步骤见 `cotton-community/README.md`。

农资商城、农机租赁、棉花交易、贷款与保险业务办理、期货开户与交易、商户后台和支付能力不属于公共服务平台范围。棉花金融仅提供知识教育和官方渠道核验指引。

## 与 cotton-app 共用后端

小程序不会在本目录启动第二套后端。API 地址由 `utils/auth.js` 管理，当前沿用 `cotton-app` 的环境配置：

- `prod`：正式 HTTPS 域名。
- `server`：云服务器 IP。
- `real`：局域网开发机地址，适合真机联调。
- `local`：`127.0.0.1`，适合微信开发者工具模拟器。

当前 `ENV` 设置为 `server`，小程序直接连接云服务器 `http://101.34.207.252`。微信开发者工具调试时需要按项目需要开启“不校验合法域名”；该 HTTP IP 不能作为正式发布配置，正式上传前必须改用已备案且配置 HTTPS 的合法域名。

开发前请在 `utils/auth.js` 中确认 `ENV` 与对应地址。真机不能把 `127.0.0.1` 当作电脑；应使用电脑局域网 IP，并确保手机与电脑处于同一网络、防火墙允许 Node 服务端口。

当前已切换为 `ENV = 'sim'`，微信开发者工具模拟器通过本机 Nginx 统一访问
`http://192.168.0.22`，使用本地 Docker MySQL。采用局域网地址是为了绕过部分 Windows
开发者工具对 `127.0.0.1` 请求的限制。上传体验版或正式版前必须改为 `ENV = 'prod'`；
真机联调则改为 `ENV = 'real'` 并确认 `LOCAL_IP` 是电脑当前局域网地址。

本地 MySQL 统一使用 `cotton_dev_mysql_data`。根目录 `.env` 和 `.env.development` 均显式设置 `MYSQL_VOLUME_NAME=cotton_dev_mysql_data`，因此直接运行 `docker compose` 或使用 `scripts/dev-local.ps1` 都会连接同一套本地账号、地块和业务数据。服务器未设置该变量时仍默认使用 `cotton_mysql_data`，避免本地开发配置改变线上已有数据卷。禁止使用 `docker compose down -v` 或手工删除 `cotton_dev_mysql_data`。
本地私有项目配置已设置 `setting.urlCheck=false`，允许开发者工具请求本机 HTTP 地址；正式版仍由微信平台配置的合法域名控制。网络请求失败时，Console 会输出 `[api-request-failed]` 及实际 URL 和微信错误信息，不记录密码或令牌。

## 新 AppID 与共用账号的注意事项

不同微信小程序的 OpenID 不相同。共享后端现在支持主小程序和公共服务小程序两套微信配置：

```env
WX_APPID=原小程序AppID
WX_SECRET=原小程序AppSecret
PUBLIC_WX_APPID=公共服务小程序AppID
PUBLIC_WX_SECRET=公共服务小程序AppSecret
```

如果暂时没有配置 `PUBLIC_WX_APPID` 和 `PUBLIC_WX_SECRET`，公益前端会回退使用原小程序配置，便于使用同一个 AppID 联调。换成独立 AppID 后必须填写公益配置并重启后端。

公共服务小程序发送 `X-Miniapp-Client: cotton-public`，后端据此选择微信配置。手机号账号仍保存在共享 `users` 表；不同小程序的 OpenID 保存在 `mini_program_identities` 表，该表通过无符号用户 ID 外键连接现有用户数据。同一微信开放平台主体下如能取得 UnionID，后端优先将身份关联到已有用户；否则通过授权手机号关联共享账号。

### 注册登录接口

| 功能 | 接口 | 说明 |
| --- | --- | --- |
| 手机号注册 | `POST /api/auth/register` | 创建共享农户账号和农户资料并返回 JWT |
| 密码登录 | `POST /api/auth/login` | 按手机号和密码登录共享账号 |
| 微信一键登录 | `POST /api/auth/wx-login` | `wx.login` + 微信手机号授权，自动注册或关联农户 |
| 登录态校验 | `GET /api/auth/verify` | 小程序启动时验证 JWT 并刷新用户资料 |
| 退出登录 | `POST /api/auth/logout` | 客户端清理 JWT；服务端保留无状态接口 |

## 数据边界

- 共用：农户基础账号、地块、农事记录、气象、专家内容、AI 服务。
- 公共服务平台独有：资讯栏目、课程体系、学习进度、考试、学习积分、证书、棉花金融科普阅读状态，以及只用于信息展示的农机/农资产品目录。
- 不进入公共服务平台：商品交易、营销、交易订单、农机支付、微信分账和商户结算。

目前课程与资讯使用前端演示数据，用于确定信息架构和交互。下一阶段应在共享后端增加公益内容 API 和独立数据表，避免把正式运营内容长期写在小程序代码中。

棉花金融首版内容保存在 `utils/finance-data.js`，阅读状态按当前登录账号保存在本机，仅用于展示阅读进度。正式运营前应增加金融科普内容审核、版本、生效时间和来源管理；实时行情若后续接入，必须使用有授权的数据源，展示采集时间、延迟状态、品级、地区、单位和免责声明。

政策中心当前同样使用明确标识的演示数据。正式上线政策内容前，必须建立政策运营后台和审核流程，并保存政策层级、类别、文号、发布单位、发布时间、生效状态、适用地区、申报截止时间及政府原文链接。

## 安全要求

- AppSecret、JWT_SECRET、AI Key、天气 Key 只能保存在后端 `.env`，不得写进小程序。
- 小程序只保存服务端签发的 Token。
- 正式环境必须使用 HTTPS，并在微信公众平台配置合法域名。
- 两个前端共用后端不等于共用所有权限；后端仍需对用户和资源归属进行校验。
- 当前 `F:\cotton` 的运行配置已与服务器备份的同名变量同步，本地启动后端可能直接连接线上数据库和服务；执行注册、删除、支付、迁移或测试数据脚本前必须先确认影响范围。
